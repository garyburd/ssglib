# 35mm slide feeder (LEGO Technic)

A gravity-assisted **linear shuttle** that feeds mounted 35mm slides onto a photography gate, then drops the previous slide into a bin. Designed around LEGO Technic beams used as rails, with the **smooth side of the beam** as the running surface.

This folder is a standalone design package. It is not part of the ssglib Lua API.
